# 构建资产清单（assets manifest）

本安装包的 `android/app/src/main/assets/` 下有四个文件不打进版本库。
**没有它们，`build.cmd` 会构建出一个不含运行环境的空壳 APK。**

本文件记录每个资产的**确切字节数**与 **SHA-256**，用于校验取到的文件是否完整。

---

|---|---|---|---|
| `rootfs.gz.bin` | 394,325,574 | `F418AFE249412082886B354F0667953ADEB5F50FB817D2C9A46653CBBFE5A3F9` | 从 Debian rootfs 打包（见第二节） |
| `pnpm-incr.gz.bin` | 23,219,739 | `9C8E214FE67706A4F166F337A7F0ADD4DFE7D3837B7D611F34BB0B881B632993` | `node android/tools/build-pnpm-incr.js` |
| `mobile-adapt.gz.bin` | 125,811 | `6397F92817A49D2118371DC062DA27D86CCFEE844D6DD8D1508CE9D3599621D3` | `node _pk.cjs`（从 `_plugin-src/`） |
| `使用指南.md` | 8,259 | `A396DADBAD67652F27CC7E1884EC6446DACBF851299F654BF0F6E9C9E257892B` | 仓库内自带（唯一入库的一个） |

★ 上表对应 **v1.0.3**。改过插件源码后 `mobile-adapt.gz.bin` 的哈希会变 —— 那时以重新生成的为准，本表需同步更新。

## 二、取资产的两种途径

### 途径 A：从已发布的 Release 附件里取（推荐）

Release 页面上传的是**完整 APK**，不是单独的 assets。若要单独文件，需要从 APK 里解出来：

```bash
# 解出 assets/（APK 本身就是 zip）
unzip -o DeepseekHarnessMobile-v1.0.3.apk 'assets/*' -d /tmp/apk-assets
cp /tmp/apk-assets/assets/*.gz.bin android/app/src/main/assets/
cp "/tmp/apk-assets/assets/使用指南.md" android/app/src/main/assets/
```

★ APK 内这三个资产是 **DEFLATE 压缩存储**的（`rootfs.gz.bin` 压缩后 392,099,665 B），
`unzip` 会自动解开，解出来的字节数应当等于第一节表里的数字。**解完请比对 SHA-256。**

### 途径 B：自己生成

1. **`mobile-adapt.gz.bin`** —— 任何机器都能生成：
   ```bash
   node _pk.cjs
   ```
2. **`pnpm-incr.gz.bin`** —— 需要本机已有 pnpm 源：
   ```bash
   node android/tools/build-pnpm-incr.js
   ```
3. **`rootfs.gz.bin`** —— 最麻烦的一个。需要一台 arm64 Linux（或 qemu）做出 Debian 13 (trixie)
   rootfs，装好 Node.js 与 `@deepseek-ai/dsh`，然后按下面的规矩压：

   ```bash
   tar -cf rootfs.tar -C <rootfs目录> .
   gzip -6 -c rootfs.tar > rootfs.gz.bin
   ```

   ★★ **三条会静默毁掉 rootfs 的坑**（都踩过）：
   - **符号链接必须真建成 symlink** —— rootfs 里有 501 个（`bin → usr/bin` 等）。
     当普通文件写会导致 `bin/sh` 不存在，容器起不来。
   - **`--exclude` 必须用相对路径**，例如 `tar -C $RF . --exclude=./tmp`；写绝对路径匹配不上。
   - **压缩前先扫一遍凭据**：曾经把 `./root/.npmrc`（含真实 npm token）与 `./root/.dsh-web-url`
     一起打了进去，发到了公开 Release。**打包前必须确认这类文件不存在。**

   ★ 校验条目数：正常是 **82,392** 条。
     ```bash
     tar -tzf rootfs.gz.bin | wc -l
     ```

## 三、校验脚本

拿到文件后跑一遍（PowerShell）：

```powershell
$dir = 'android\app\src\main\assets'
@{
  'rootfs.gz.bin'      = 'F418AFE249412082886B354F0667953ADEB5F50FB817D2C9A46653CBBFE5A3F9'
  'pnpm-incr.gz.bin'   = '9C8E214FE67706A4F166F337A7F0ADD4DFE7D3837B7D611F34BB0B881B632993'
  'mobile-adapt.gz.bin'= '6397F92817A49D2118371DC062DA27D86CCFEE844D6DD8D1508CE9D3599621D3'
}.GetEnumerator() | ForEach-Object {
  $p = Join-Path $dir $_.Key
  if (-not (Test-Path $p)) { Write-Host "缺失 $($_.Key)" -ForegroundColor Red; return }
  $h = (Get-FileHash $p -Algorithm SHA256).Hash
  if ($h -eq $_.Value) { Write-Host "OK   $($_.Key)" -ForegroundColor Green }
  else { Write-Host "MISMATCH $($_.Key)`n  期望 $($_.Value)`n  实际 $h" -ForegroundColor Red }
}
```

三个全 `OK` 才能构建。

## 四、为什么这些文件不进版本库

| 原因 | 说明 |
|---|---|
| 体积 | 合计 **393 MB**，git 仓库会变得无法克隆 |
| 可重建 | 两个小的能脚本生成；rootfs 能按第二节重建 |
| 含凭据风险 | rootfs 里可能残留 `.npmrc` / 会话 token —— 每次打包都必须重新扫 |

★ 另外：**备份文件绝不能放在 `assets/` 里**。Gradle 会把 `assets/` 整个打进 APK，
曾因此让 APK 从 402 MB 涨到 774 MB。`.gitignore` 里已用
`android/app/src/main/assets/*.bak-*` 与 `*.tmp` 挡住。
