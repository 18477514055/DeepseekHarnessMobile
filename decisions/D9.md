# D9 · 2026-10-20 · 对外文本一律产品文档口吻，受众是第三方

**决策**：README、使用指南、注释、发布说明 —— 全部按**产品文档**写，不用「跟用户对话」的口气。

**依据**（用户原话）：
> 「各项文本说明更加官方化一点，不是写给我的，是写给其他人的。」

**具体口径**：
| 不写 | 改写 |
|---|---|
| 省得你自己探测 | 运行环境说明 |
| 别浪费时间 / 别靠猜 / 别建议这些 | 以下能力在本环境中不可用 / 判定应依据… / 无法解决此问题 |
| 让用户自己看（最省事） | 由使用者在设备上查看 |
| 告诉用户真正原因 | 向使用者说明根本原因 |

★ 统一术语：**使用者**（不写「用户」）、**本应用**、**本安装包**。
★ 技术细节与判据**全部保留**，只改语气与措辞 —— 不许为了「官方」把有用的细节删掉。
