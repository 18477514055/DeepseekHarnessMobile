# D3 · 2026-10-19 · 保活三件套必须齐全，缺一不可

**依据**（实测 `logcat -b events`）：
```
am_kill : [0,11436,com.termux,200,SwipeUpClean,160028]
```
`oom_adj=200`，而四个脚本里 `grep -c wake-lock` = 0 ⇒ **从来没人拿过 wake lock**。

**三件套**：
1. 前台服务类型必须 `specialUse`（`dataSync` 在 targetSdk≥35 时后台累计 6 小时会被停）；
2. 进程内拿 `PARTIAL_WAKE_LOCK`；
3. 引导用户手动开 HyperOS 白名单（**无 API**，只能做引导页）。

另：`max_phantom_processes` 读到 `null` ⇒ 本机未启用 phantom 清理，不用处理那一套。
