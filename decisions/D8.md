# D8 · 2026-10-20 · 临时 proot 必须带 `--change-id=0:0`

**决策**：凡是在容器内执行需要 root 身份的操作（`adb install-client` 的 apt、dpkg 等），
临时起的 proot 必须与主容器一样带 `--change-id=0:0`。

**依据**（boot.log 逐字，2026-10-20 15:01）：
```
[ADB] 安装客户端结果: Use of uninitialized value in concatenation ...
      | dpkg: error: requested operation requires superuser privilege
      | E: Sub-process /usr/bin/dpkg returned an error code (2)
      | INSTALL_FAILED |
```
⇒ 临时 proot 漏了这一条 ⇒ 容器内身份是 **uid 10420（app uid）** 而不是 root ⇒ dpkg 拒绝。

★ **这一条曾经被我误判成「服务端 15 秒超时」** —— 表象一样（都是失败 + 页面读不到），
真因是权限。**教训：日志里有 `INSTALL_FAILED` 时，要读它上一行是什么错。**
