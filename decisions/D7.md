# D7 · 2026-10-20 · 默认工作区用官方 `documentsDirectory` 覆盖入口，**不改官方代码**

**决策**：在家级 `$DSH_HOME/cordis.patch.yml` 里给 `workspace-controller` 配
`documentsDirectory: "/root/.dsh"`，**不改** `dsh-api-workspace-controller` 的源码。

**依据**（源码级）：
- `dsh-api-workspace-controller/lib/index.js:609-641` 的 `defaultWorkspaceDirectory()`：
  `if (directory === void 0)` 才进 switch；Android 上 `process.platform === "linux"` ⇒ 走
  `xdg-user-dir DOCUMENTS` 分支 ⇒ **精简 Debian 里没这个命令**（82,392 条目里零命中）
  ⇒ spawn 失败 / stdout 为空 ⇒ 抛「system Documents directory is unavailable」⇒ **首启建不出工作区**。
- 同文件 L846 `documentsDirectory: z.string()`，注释写着「explicit deployment override for the
  system Documents directory」—— **这就是官方留的覆盖入口**。
- 最终路径 = `join("/root/.dsh", "deepseek-harness", "default-workspace")`
  = `/root/.dsh/deepseek-harness/default-workspace`（宿主 `files/dshhome/...`）。

★ 写**家级** patch 而不是 `profiles/<名>/cordis.patch.yml`：后者会被「重建 profile」删掉
（源码 L134 明确写着重置时 delete "its dependencies and **user patch**"）。

**实测验证**（2026-10-20 19:32，一台**全新安装、零历史工作区**的 Android 15 设备）：
`workspace.json` 由 227 B 空状态 → 696 B，`defaultWorkspaceId` 有值，
`path` 正是上面那条，`createdAt` 是首次打开页面那一刻 —— **DSH 自己建的**。
★ 注意前置条件：`initializeDefault` 只在「全空状态」跑（`dsh-workspace/lib/index.js:431`），
**老用户机器上验不出效果不等于没修好**。
