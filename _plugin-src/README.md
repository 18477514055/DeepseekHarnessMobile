# dsh-mobile-adaption

DSH Web UI 的**移动端适配插件**（手机竖屏优先）。

给 DSH（DeepSeek Harness）的网页界面补上手机需要的交互：三栏变覆盖层侧栏、设置面板两页全屏、
余额胶囊、⋮ 菜单注入、软键盘隔离、系统返回键接管、边缘滑动。

---

## 装它之前请先了解

本插件**通过改写官方页面的 DOM/CSS 来实现**移动端交互，而不是调用官方 UI 的插槽 API。
原因是官方在移动端没有留出对应的座位（例如"整屏抽屉式侧栏"官方没有接口）。

**这意味着：**

- 官方升级后，**某些功能可能静默失效**（退回官方原生行为），需要适配
- 插件本身做了**兜底降级**：每项功能独立加载，一个坏了只关那一个，**不会白屏**
- 内置**契约体检**：`dsh-mobile-doctor` 能一眼看出官方哪些内部实现变了

如果你只想要"能装插件、升级不出事"，官方插槽能覆盖的功能应当优先用官方 API。
本插件的价值在**补官方留空的移动端交互**。

---

## 装

```sh
dsh plugin --profile web add dsh-mobile-adaption
```

或从本地/压缩包安装。装完刷新页面（客户端半不需要重启服务；服务端半需要重启一次）。

---

## 包含什么

| 功能 | 说明 |
|---|---|
| 侧栏整屏覆盖层 + 滑动 | 网格恒定不重排，只用 `transform`（手机上不掉帧） |
| 边缘滑动开关侧栏 | 屏幕边缘右滑呼出、左滑收起 |
| 设置面板两页全屏 | 含退出残影（官方面板是"打开才挂载"） |
| 余额胶囊 + 详情面板 | 显示账户余额与 Token 用量（数据来自运行期的 `dsh-usage.json`） |
| ⋮ 菜单注入 | 把「Agent 预设」「后台任务」「刷新页面」收进会话头 ⋮ 菜单 |
| 软键盘隔离 | 切会话/新建对话时不自动弹键盘 |
| 系统返回键接管 | 先关掉本页的层，再交给 App |
| **模型选择：搜索 + 平台筛选** | 官方模型弹层本身没有搜索框（到 0.1.7-alpha.2 都没有），插件在列表上方补一个：输入即筛模型名，chips 按平台（provider 分组标题）筛选，再点一次取消；空结果显示「没有匹配的模型」 |
| **输入框座位收纳（上拉列表）** | 手机上输入框空间不足，插件往工具行（`conversation.input.left` / `.right`）注册的座位会把输入栏挤开、上下错位。本插件在输入卡片下方留一个「附加选项」上拉按钮，**自动**把工具行里第三方插件注册的座位收进底部抽屉；宽屏（>820px）保持原样 |
| 报告路由（服务端半） | `POST /dsh-mobile/report` 落盘健康/契约报告 |

## 上线状态与体检

插件自带两个标记，便于判断它到底有没有正常加载：

- `window.__dshMobileHealth` —— 每项功能的加载状态（`ok` / `fail` / `pending`）
- `window.__dshMobileContract` —— 官方契约探测结果（哪些内部实现还在、哪些失效）

配套命令（随本项目分发）：

```sh
dsh-mobile-doctor        # 读契约体检报告
dsh-mobile-safe-mode on  # 界面坏了 → 摘掉本插件、回落官方原生界面
```

---

## 已知限制

- 官方升级后**需要适配**（见上）。这不是缺陷，是"改别人页面"的固有代价。
- 依赖若干官方 CSS Modules 类名与 `data-*` 属性；已集中登记在源码的 `CONTRACT` 里，
  便于升级后定点修复。
- 桌面上（鼠标指针）不会误启移动 UI 的假设**尚未做**——本插件假定运行在手机上。
