## 教训 L5 · 记录错
- 标题: 对外文档的数字最容易腐坏
- 现象: README 同时写错三处：rootfs `~392 MB`、插件 `~76 KB`、首启 `30~60 秒`；实际是 376 MB / 123 KB / 94~107 秒。
- 根因: 数字是 1.0.0 时期抄下来的，之后 rootfs 重打包、插件不断长大、启动链变长，**没有一个数字跟着更新**。而这类错误危害最大：别人照着它判断"是不是卡死了"。
- 正解: 体积数字一律用 `Get-ChildItem` 当场量；耗时用 boot.log 的时间戳差（`bootContainer 开始` → `就绪，token 已取到`）算。不能沿用旧版本。
