## 教训 L6 · 守卫错
- 标题: 加了整套功能却一个字节都没生效
- 现象: 写完「检查更新」的完整实现、语法检查通过、打包装机，菜单里却什么都看不到。
- 根因: **菜单注入器那行 `feature("menuInjector", ...)` 从 2026-10-19 就被注释掉了**。代码全对，注册那行不生效，行为零变化。我犯的错是一上来就改实现，没先确认这条 feature 到底有没有被注册。
- 正解: 加菜单项 / 加 feature，**第一步先确认 `feature(...)` 有没有被注册**。想恢复注入器时必须同时移除 `syncMovedChips()` 与 `data-dsh-moved-*` 标记，否则官方「后台任务 / Agent 预设」两个 chip 会被藏掉且没有替代品。
- 适用范围: 给插件加任何新功能时
- 相关文件: _plugin-src/lib/client.js
